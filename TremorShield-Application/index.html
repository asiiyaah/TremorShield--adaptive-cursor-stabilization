A steadier line for an unsteady hand.

TREMORSHIELD is a software-only cursor stabilizer for people with hand tremor. It watches how you move, tells intentional motion from tremor, and smooths the difference — no extra hardware required.

THE PROBLEM

Small movements get in the way of everyday computer use.

Hand tremor turns simple pointing, clicking, and dragging into repeated corrections. Most existing fixes ask for specialized hardware or apply the same fixed filter to every user and every task.

Fixed filtering

A single filter setting can't tell a deliberate flick from a tremor spike, so it either over-smooths or under-corrects.

No task awareness

Navigating, clicking, and dragging need different amounts of assistance, but most tools treat every action the same.

Hardware dependence

Several assistive approaches rely on eye-tracking rigs or dedicated controllers rather than a standard mouse.

HOW IT WORKS

Three stages between your hand and the pointer.

Each stage runs on every movement, adjusting itself as your motion and task change.

01

Adaptive filtering

A self-adjusting filter estimates your true intended position from noisy raw input, updating its own sensitivity as conditions change.

02

Confidence scoring

A separate score reads your motion pattern to judge how deliberate the current movement looks, and how much help it needs.

03

Smoothed output

A lightweight smoothing pass blends the result into a steady, responsive cursor path without noticeable lag.
